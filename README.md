# てんき服

地域の天気予報から、その日の服装を提案するWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要・APIキー不要）。

- 主要都市ボタン、市区町村名の検索、「📍 現在地」から地域を選べます
- 「☆ お気に入りに追加」で、よく見る地域を検索欄の下に登録できます
- 最後に見た地域は次回起動時に自動で表示されます
- 設定（お気に入り・暑がり/寒がり・外出時間）はブラウザに保存されます

## 機能

- 現在の天気（気温・体感・湿度・風速）
- 今日・明日の服装の提案（外出時間帯の体感最高気温をもとに8段階）。18時以降は明日を自動表示
- 服装のイラスト（傘・手袋・帽子・マスクなども天気に合わせて表示）
- 持ち物チェックリスト（傘・日焼け止め・手袋・マスクなど。チェックは日付ごとに保存）
- PM2.5・黄砂の目安と、花粉の観測情報（花粉は2〜5月、県庁所在地の観測値）
- 前日のお知らせ通知（指定時刻に明日の服装を通知。ページを開いている間のみ）
- お気に入りの地域をスワイプ・横スクロールで切り替え
- 旅行モード（「🧳 旅行」タブ）
  - 行き先と日付を入れると、日ごとの天気と服装・旅行全体のまとめ・荷物リスト（服の枚数と持ち物）を表示
  - 日ごとに行き先を変えられる（例：1〜2日目は札幌、3日目は旭川）
  - 出発地（自宅）との気温差を表示
  - 16日より先の日は、過去3年の同じ日の天気から「平年」の目安を表示
  - 旅行の予定は最大10件までブラウザに保存
- 昨日との比較（「昨日より1枚多めに」など）
- 暑がり・寒がり設定（体感を ±3℃ 補正）
- 外出時間の設定（その時間帯の気温・雨・風で判断）
- 注意点：寒暖差、雨・雪（傘）、強風、紫外線、熱中症、氷点下
- 洗濯の目安（9〜15時の予報で ◎○△× を判定）
- 24時間の天気（3時間ごと、外出時間外は薄く表示）
- 7日間の週間予報と、各日の服装・洗濯の目安
- ホーム画面に追加できるアプリ設定（`manifest.json`）※ネット上に公開した場合のみ有効

## 服装の目安（体感最高気温）

| 体感最高気温 | 服装 |
|---|---|
| 30℃以上 | ノースリーブ・半袖 |
| 25〜30℃ | 半袖 |
| 21〜25℃ | 長袖シャツ・薄手 |
| 17〜21℃ | カーディガン・薄手の羽織 |
| 13〜17℃ | セーター・ジャケット |
| 9〜13℃ | トレンチコート・薄手のコート |
| 5〜9℃ | 冬物コート |
| 5℃未満 | ダウン・マフラー・手袋 |

基準は `app.js` の `OUTFITS`、注意点の条件は `buildAdvice()` で調整できます。

## ファイル構成

- `index.html` — 画面
- `style.css` — デザイン（ダークモード対応）
- `app.js` — 天気の取得と服装の判定、イラストの描画
- `sw.js` — 通知を出すためのサービスワーカー

## データ

- 気象データ（予報・過去の天気）・大気質（PM2.5・黄砂）・地名検索：[Open-Meteo](https://open-meteo.com/)（CC BY 4.0、非商用利用は無料）
- 花粉：[ウェザーニューズ](https://wxtech.weathernews.com/)（花粉観測オープンデータ）
- 現在地の地名：[BigDataCloud](https://www.bigdatacloud.com/)（Free Client-side Reverse Geocoding API）
